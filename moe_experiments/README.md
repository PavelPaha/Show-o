# MoE Experiments - Domain-Specific Datasets

Экспериментальные датасеты для исследования работы Mixture of Experts (MoE) в модели Show-o.

## Загруженные датасеты

### TextVQA

**Описание**: TextVQA — вопросно-ответный датасет, где вопросы задаются про текст, видимый на изображениях.

**Доменная специфика**: 
- Фокус на понимание текста на изображениях (OCR + понимание)
- Вопросы про вывески, упаковки, книги, экраны устройств
- Требует комбинирования визуальной и текстовой информации

**Статистика**:
- Используется: 1000 примеров из train split
- Полный датасет: ~28,000 примеров (train split)
- Формат: VQA (вопрос + ответ(ы))
- Источник: Hugging Face `textvqa`

**Путь**: `moe_experiments/data/textvqa/`

**Структура**:
```
textvqa/
├── train.json      # JSON с вопросами и ответами
└── images/         # PNG изображения
```

**Формат train.json**:
```json
[
  {
    "image": "textvqa_0054c91397f2fe05.png",
    "question": "what is the brand of phone?",
    "answers": ["nokia", "nokia", "nokia", "nokia", "toshiba"],
    "answer": "nokia"
  }
]
```

## Цель экспериментов

Исследовать, выделяются ли отдельные эксперты в MoE под конкретные домены MMU (Multimodal Understanding) задач.

## Запуск загрузки

**ВАЖНО**: Скрипт загружает по **1000 семплов** каждого датасета!

```bash
# Активировать окружение
source .venv/bin/activate

# Перейти в директорию moe_experiments
cd moe_experiments

# Загрузить TextVQA (1000 семплов)
python download_full_datasets.py --textvqa

# Загрузить VQAv2 (1000 семплов)
python download_full_datasets.py --vqav2

# Загрузить все доступные датасеты (по 1000 семплов каждый)
python download_full_datasets.py --all
```

**Примечание**: Ограничение в 1000 семплов установлено для быстрого старта экспериментов. При необходимости можно изменить значение `max_samples` в скрипте.

## Интеграция с проектом

Эти датасеты находятся **отдельно** от основного проекта и не трогают его код. Для экспериментов можно создать отдельный pipeline или скрипты в директории `moe_experiments/`.
