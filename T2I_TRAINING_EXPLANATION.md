# 🎨 Как должно выглядеть обучение T2I в Show-o

## 📋 Общая схема обучения

### 1. Подготовка данных для T2I

**Входные данные:**
- Изображение: `pixel_values` (B, 3, 512, 512)
- Текст (caption): `texts` (список строк, например: "A red car on the street")

**Что происходит:**

1. **Кодирование изображения в токены:**
   ```python
   image_tokens = vq_model.get_code(pixel_values)  # (B, 256) - 256 токенов для 512x512
   image_tokens = image_tokens + len(text_tokenizer)  # Сдвиг для разделения text/image токенов
   ```

2. **Маскирование токенов изображения (MLM - Masked Language Modeling):**
   - Часть токенов изображения маскируется (заменяется на `<mask>`)
   - Создаются `labels` - правильные токены для предсказания
   - `mask_prob` - вероятность маскирования (обычно 0.5-0.8)

3. **Формирование последовательности:**
   ```
   [<|t2i|>] [BOS] [text tokens] [EOS] [<|soi|>] [masked image tokens] [<|eoi|>]
   ```
   
   Где:
   - `<|t2i|>` - специальный токен задачи text-to-image
   - `text tokens` - токенизированный caption (до max_seq_length=512)
   - `<|soi|>` - Start of Image
   - `masked image tokens` - замаскированные токены изображения
   - `<|eoi|>` - End of Image

### 2. Forward pass модели

**Вход:**
- `input_ids`: полная последовательность (text + masked image tokens)
- `attention_mask`: маска внимания
- `labels`: правильные токены для предсказания (ignore_index=-100 для не-маскированных)

**Что делает модель:**
1. Эмбеддинги токенов (text + image)
2. Transformer forward pass
3. Предсказание logits для каждого токена

**Выход:**
- `logits`: (B, seq_len, vocab_size) - предсказания для каждого токена

### 3. Вычисление Loss

**T2I Loss вычисляется только для токенов изображения:**

```python
# Берём только часть после текста (image tokens)
logits_t2i = logits[:batch_size_t2i, max_seq_length + 1 :]  # После <|soi|>
labels_t2i = labels[:batch_size_t2i, max_seq_length + 1 :]

# Cross-entropy loss только для замаскированных токенов
loss_t2i = F.cross_entropy(
    logits_t2i.contiguous().view(-1, vocab_size),
    labels_t2i.contiguous().view(-1),
    ignore_index=-100  # Игнорируем не-маскированные токены
)
```

**Важно:**
- Loss вычисляется **только для замаскированных токенов изображения**
- Текстовая часть игнорируется (ignore_index=-100)
- Модель учится предсказывать замаскированные токены изображения по тексту

### 4. Что должно происходить во время обучения

#### ✅ Правильное поведение:

1. **Начальный loss (step 0-100):**
   - `loss_t2i`: ~8-12 (высокий, модель не умеет предсказывать)
   - `mask_prob`: ~0.5-0.8 (в зависимости от schedule)

2. **Первые шаги (step 100-1000):**
   - `loss_t2i` должен **постепенно снижаться**: 12 → 10 → 8 → 6
   - Небольшие флуктуации нормальны
   - `mask_prob` может меняться по schedule

3. **Средние шаги (step 1000-10000):**
   - `loss_t2i` продолжает снижаться: 6 → 4 → 3 → 2.5
   - Более стабильное снижение
   - Модель учится связывать текст и изображение

4. **Долгосрочное обучение (step 10000+):**
   - `loss_t2i` стабилизируется: 2.5 → 2.0 → 1.8
   - Медленное снижение
   - Модель улучшает качество генерации

#### ❌ Проблемные признаки:

1. **Loss не снижается:**
   - `loss_t2i` остаётся постоянным (например, всегда ~8.5)
   - **Причины:** слишком низкий LR, замороженные параметры, неправильные labels

2. **Loss = 0 или NaN:**
   - Все labels игнорируются (ignore_index)
   - Проблема с маскированием или slicing

3. **Loss растёт:**
   - Слишком высокий LR, нестабильное обучение

4. **Loss флуктуирует сильно:**
   - Слишком высокий LR или маленький batch size

### 5. Диагностика в логах

**Что смотреть в логах:**

```
Step 100: t2i diagnostics - 
  batch_size_t2i=2, 
  loss_t2i=8.2341, 
  non_ignore_labels=256/512,  # ✅ Должно быть > 0!
  mask_prob=0.6500,
  loss_t2i.requires_grad=True  # ✅ Должно быть True!
```

**Критичные проверки:**
- `non_ignore_labels > 0` - есть токены для обучения
- `loss_t2i.requires_grad=True` - градиенты вычисляются
- `mask_prob > 0` - токены маскируются
- `loss_t2i` снижается со временем

### 7. Ключевые параметры

**Критичные для T2I:**
- `learning_rate`: 1e-5 (не слишком низкий!)
- `max_seq_length`: 512 (должно совпадать с resolution!)
- `mask_prob`: 0.5-0.8 (достаточно маскирования)
- `batch_size_t2i`: 2+ (больше = стабильнее)
- `gradient_accumulation_steps`: 48 (эффективный batch size)

**Проверка:**
- Все параметры модели должны иметь `requires_grad=True` (кроме замороженных)
- Градиенты должны быть ненулевыми
- Loss должен иметь градиенты (`loss.requires_grad=True`)
